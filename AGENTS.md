# AGENTS.md

This repository is public. When producing or editing a skill here, keep the skill abstract: describe roles, steps and interfaces in generic terms, and never include machine names, user names, host or network addresses, local paths, repository names, or any other personal or environment-specific fact. Such facts belong in the private contract documents of the workspace that consumes the skill; a skill reads them from the contract at run time, through placeholders it declares as its contract interface. Before committing, check the diff for any such literal.
